## 🚀 快速开始

### 开发环境
- IDE：Keil MDK-ARM 5
- 代码生成：STM32CubeMX
- 调试器：JLink V9

### 编译与烧录
1. 用 Keil 打开 `MDK-ARM/TR_Project.uvprojx`
2. 选择对应的芯片型号（STM32F407VET6）
3. 编译（F7）并下载（F8）至目标板

> 注意：外部晶振为 8MHz，CubeMX 工程中已按此配置，若更换晶振需同步修改。
